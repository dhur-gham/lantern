# Stress suite

Adversarial tests against the package under Testbench (Lantern enabled, SQLite, in-process requests).

```
php vendor/bin/phpunit --testsuite Stress                       # everything (~8 s, 261 tests)
php vendor/bin/phpunit --testsuite Stress --exclude-group bug   # known-good set (248 tests, all green)
php vendor/bin/phpunit --testsuite Stress --group bug           # the open bugs below (13 tests, all red)
```

`phpunit.xml`: added the `Stress` suite and excluded `tests/Stress` from the `Lantern` suite so the default run stays as it was.
Tests live in `tests/Stress/`; shared fixtures (models, controllers, middleware, form requests, a `/scenario/{name}` route) are in `tests/Stress/Support/Fixtures.php`, the base class is `StressTestCase`.
Failing tests are kept and tagged `@group bug`; none were deleted or weakened. No file under `src/` was touched.

Coverage: exceptions in middleware / controller / view / FormRequest (rules, authorize, prepareForValidation) / listener / resource; redirects, 404/405/422, streamed, binary, download, 204, empty, JSON, HEAD/OPTIONS; nested/rolled-back transactions and savepoints (30 deep); failed queries caught by the app (syntax, missing table, unique, deadlock retries, 50 in a row); 10k-row results, giant/binary/unicode/emoji/null/date/named bindings, 5k queries per request (time and memory bound), 10k spans at depth 200, 1000-deep trace storage; multiple connections, read/write split, purge/reconnect, storage connection; Eloquent lazy loops, withCount, chunk/chunkById/cursor/lazy, pagination, soft deletes, polymorphic, N+1 in Blade/Resource/accessor/observer/listener/sync job; `preventLazyLoading` with an app callback (still called), prevention without callback (framework exception kept), never enabled (no exceptions introduced); config toggles (disabled, kill switch, sampling, ignore_paths, ignore_tables, ignore_sql_patterns, capture_bindings, call_site_mode, detectors, caps, sink limit, last-trace file); storage failures (missing tables, DB down, purged connection, 10 MB payload, invalid UTF-8/NAN/resources, malformed payloads, gzip on/off, batching, tail sampling); fingerprint property tests (seeded random literals / IN lists / multi-row inserts); detector thresholds at n-1, n, n+1 and severity boundaries; 500 sequential requests (memory flat, listeners/terminating callbacks stable, evicted traces freed); dashboard/API auth (local vs production, custom gate, no binding leak when unauthorised).

## Observations (not bugs, behaviour worth knowing)

- Head sampling (`sampling_rate`) is skipped whenever `runningInConsole()` is true, so under phpunit `sampling_rate = 0` still records. The suite tests `Sampler` directly and forces `isRunningInConsole = false` for the provider-level check (`HeadSamplingTest`, passes).
- `mergeConfigFrom` is a shallow merge: an app that sets a partial `lantern.storage` array silently loses `compress` (it reads as `false`) and `connection`. Standard Laravel behaviour, but the provider reads `compress` with a `false` fallback while the shipped default is `true`.
- Queries the app itself runs on the configured `storage.connection` are never recorded (the connection is ignored by name). Pinned by `MultiConnectionTest::test_storage_connection_ignores_app_queries_on_that_connection_by_design`.
- `OPTIONS` on an existing route is answered 200 by the framework (not 405); Lantern traces it normally. Dashboard `OPTIONS` returns an empty body, no leak.
- 500 exception requests grow process memory by about 40 KB each (about 21 MB over 500) with or without Lantern; it is the framework/testbench exception path, not Lantern. Lantern's own state is verified flat: evicted traces are freed (`WeakReference`), listeners and terminating callbacks do not accumulate.
- The existing `DisabledTest.php` defines `KillSwitchTest` in the same file; PHPUnit 11 only runs the class named after the file, so that class may never run. Not touched (outside `tests/Stress`). The stress suite keeps one class per file.
- Another agent was editing `src/` while this suite was written (a transient fatal in `src/Agent/AgentCommand.php` cleared on its own); results above are against the tree as of the last run.

## Status

All bugs listed above are fixed and their tests no longer carry `@group bug`: payload codec (malformed gz, deep trees),
chunk/lazy paging false positives, fingerprint edge cases (huge IN lists, operator spacing, escaped quotes) and
per-connection duplicate detection. Run `php vendor/bin/phpunit --testsuite Stress` (261 tests, about 8 s).
